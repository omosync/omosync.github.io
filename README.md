# OmoSync

Android Auto on the OMOWAY OMO X cockpit screen (1920×720) over Wi-Fi, plus a procedural engine sound.

- Website and setup guide: https://omosync.github.io/
- Download: [Releases](https://github.com/omosync/omosync.github.io/releases/latest). Each release has the APK, its SHA-256, and the Mac/PC cockpit simulator (`omosync-simulator-<version>.zip`).

This repository holds only the download website and the signed releases. OmoSync is experimental and not affiliated with OMOWAY or Google.
